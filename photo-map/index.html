사진 읽는 중

사진으로 다녀온 곳을 찾아드려요

사진 파일에 담긴 촬영 위치(GPS)와 촬영 날짜를 읽어서, 날짜별로 어디에 있었는지 지도에 보여줘요.

  • 사진은 이 기기 안에서만 읽어요. 어디에도 올리지 않아요.
  • 휴대폰에서는 사진을 고를 때 위치가 빠질 수 있어요.
  • 사진이나 폴더를 이 창에 끌어다 놓아도 돼요.

여기에 놓으면 사진을 읽어요

사진 불러오기

휴대폰 사진에 위치가 안 나올 때

먼저 확인할 것

  • 카메라 앱 설정에서 위치 태그(위치 저장)가 켜져 있어야 사진에 위치가 기록돼요.
  • 메신저나 SNS로 받은 사진은 위치 정보가 지워져 있을 수 있어요. 원본 사진을 쓰세요.

아이폰

  • 사진을 고르는 화면에 옵션 버튼이 보이면 눌러서 위치를 켜고 고르세요.
  • 그래도 빠지면 사진 앱에서 공유 → 옵션에서 위치를 켜고 파일에 저장한 다음, 여기서 파일 앱에서 고르기로 불러오세요.

갤럭시 등 안드로이드

  • 사진 선택 화면 오른쪽 아래에 위치 정보 버튼이 있으면 켜고 고르세요. (최신 안드로이드)
  • 파일 앱에서 고르기로 내 파일 → DCIM → Camera 폴더의 사진을 고르면 위치가 남아 있는 경우가 있어요.

가장 확실한 방법

  • 사진을 PC로 옮긴 뒤, PC 브라우저에서 폴더 통째로 불러오세요.

설정

지도

키 받는 방법
  1. 카카오 디벨로퍼스에 로그인해서 애플리케이션을 하나 만들어요.
  2. 앱 키 중 JavaScript 키를 복사해 위 칸에 붙여 넣어요.
  3. JavaScript 키의 JavaScript SDK 도메인(예전 메뉴: 플랫폼 → Web → 사이트 도메인)에 아래 이 사이트 주소를 등록해요.
  4. 카카오맵 메뉴의 사용 설정에서 상태를 ON으로 바꿔요.
키 받는 방법
  1. 네이버 클라우드 플랫폼 콘솔에서 Maps 서비스의 Application을 등록해요.
  2. API는 Dynamic Map을 고르고, 주소 찾기를 쓰려면 Reverse Geocoding도 골라요.
  3. Web 서비스 URL에 아래 이 사이트 주소를 등록해요.
  4. 인증 정보의 Client ID를 위 칸에 붙여 넣어요.
키 받는 방법
  1. Google Cloud 콘솔에서 Maps JavaScript API를 사용 설정해요. 주소 찾기를 쓰려면 Geocoding API도 켜요.
  2. API 키를 만들고, 웹사이트 제한에 아래 이 사이트 주소 뒤에 /*를 붙여 등록해요.
  3. 보통 결제 계정 연결이 필요해요. 매달 무료 사용량이 있어요.
